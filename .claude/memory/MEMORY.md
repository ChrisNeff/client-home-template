# Memory index

One line per memory, linking to a detail file in this folder. Read a detail file only when its line looks relevant.

## Conventions

- **Team-shareable facts only.** No personal notes, no secrets, nothing from another client.
- **Filename:** `type_topic_words.md`, for example `feedback_branch_naming.md`.
- **Frontmatter:** `name` (kebab-case, matching the filename: `feedback-branch-naming`), `description`, and `type`, which is one of `user`, `feedback`, `project` or `reference`.
- **Expiry:** add an `**Expires:**` line to any `project` memory that is point-in-time. `user` and `feedback` entries stay valid until changed.
- **No duplicates:** if `AGENTS.md` already states it, do not record it here. Duplicated content drifts out of sync.
- **Links** between memories are plain relative markdown links, never wikilinks.
- **Index line:** `- [Title](type_topic_words.md) - one-line hook`
